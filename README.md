«Умняша — Учимся играя!» — это интерактивный образовательный сайт-тренажёр для первоклассников, совмещающий обучение с элементами популярной игры Roblox. Главным проводником по сайту выступает персонаж Милана, которая помогает детям в игровой форме подтягивать знания по математике и русскому языку.

 Игровые механики и кастомизация

Процесс обучения полностью геймифицирован, чтобы удерживать интерес ребёнка:
• Прокачка и валюта: За правильные ответы начисляются очки в виде бриллиантов (💎). Накапливая их, можно повышать уровень персонажа (например, с уровня «Новичок»), чтобы зарабатывать ещё больше бонусов за ответы.
• Гардероб Миланы: Алмазы можно тратить на кастомизацию персонажа: покупать новую одежду, причёски, обувь, аксессуары, фоны и даже новые варианты озвучки голоса.
• Система наград: За заработанные звёздочки открываются коллекционные наклейки (ракета, радуга, динозавр, корона).
• Статистика: Сайт отслеживает количество решённых заданий по предметам, рекорд серии правильных ответов подряд и автоматически сохраняет прогресс.

📚 Обучающий контент

Тренажёр разделён на два основных направления:
1. Математика (Счёт в пределах 20):
	• Практические задания, где нужно решить пример и кликнуть на правильный ответ.
	• Интерактивная шпаргалка «Состав числа 20», где при нажатии на пары чисел (например, 1+19, 2+18) Милана озвучивает их вслух.
2. Русский язык (Правила-помощники):
	• Наглядные карточки с базовыми правилами орфографии для 1 класса: правописание ЖИ-ШИ, ЧА-ЩА, ЧУ-ЩУ с примерами.
	• Подсказки по проверке безударных гласных в корне слова с помощью подбора однокоренных слов под ударением (вода → во́ды).
Платформа отлично подходит для самостоятельного повторения школьной программы, превращая рутинные упражнения в увлекательную игру-одевалку.
