«Умняша — Учимся играя!» — это интерактивный образовательный сайт-тренажёр для первоклассников, совмещающий обучение с элементами популярной игры Roblox. Главным проводником по сайту выступает персонаж Милана, которая помогает детям в игровой форме подтягивать знания по математике и русскому языку.
